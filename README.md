# QuickClipboard (LCECP)

轻量级云加密剪贴板协议 — 基于 TCP Socket 的端到端加密剪贴板同步工具。

## 1. 项目结构

```
QuickClipboard/
├── src/                # 源码
│   ├── protocol.py     # 协议定义：12 字节二进制头 + JSON 正文
│   ├── server.py       # 服务器：多线程，内存存储密文+盐值，TTL+闲置清理
│   ├── client.py       # 控制台客户端
│   └── gui_client.py   # GUI 客户端（Tkinter）
├── assets/             # 资源
│   └── app.ico         # 程序图标
├── tools/              # 工具脚本
│   └── make_icon.py    # 图标生成脚本
├── docs/               # 文档
│   ├── intro.pdf       # 实验文档
│   └── intro_text.txt  # PDF 文本提取
├── dist/               # 打包产物
│   └── LCECP.exe       # 带图标的独立启动器
├── LCECP.spec          # PyInstaller 打包配置
├── requirements.txt    # 依赖：仅 cryptography
└── README.md
```

## 2. 环境准备

```bash
pip install -r requirements.txt
```

需要 Python 3.8+，Tkinter 已内置于标准 Python 安装中。

## 3. 启动服务器

在服务器主机（本机或远程主机）上运行：

```bash
python src/server.py
```

服务器默认监听 `0.0.0.0:9000`（接受所有网卡的 9000 端口连接），启动后显示：

```
==================================
服务器正在监听 0.0.0.0:9000
==================================
```

> 如果端口被占用，修改 `src/server.py` 第 9 行的 `PORT` 值。

### 数据保留策略（服务端内存）

| 数据 | 保留时长 | 释放方式 |
|------|---------|---------|
| 剪贴板密文 + salt | 1 小时（TTL） | 后台清理线程每 60 秒扫描，过期即主动清除；用户 GET 时也有惰性兜底检查 |
| 空账户（无密文且 24 小时无活动） | 24 小时 | 清理线程直接删除账户条目，之后重新登录会创建全新账户 |
| 服务器进程退出 | — | 全部数据清空（纯内存，无持久化） |

相关常量见 `src/server.py` 顶部：`TTL_SECONDS`、`CLEANUP_INTERVAL`、`ACCOUNT_IDLE_SECONDS`。

## 4. 启动 GUI 客户端

```bash
python src/gui_client.py
```

### 4.1 连接界面

| 字段 | 填什么 | 说明 |
|------|--------|------|
| **服务器地址** | 见下表 | 服务器的 IP 地址 |
| **端口** | `9000` | 与服务器一致 |
| **用户名** | 任意 | 首次连接即自动注册 |
| **密码** | 任意 | 用于加密/解密，请记住 |

### 4.2 服务器地址怎么填？

这是最常见的问题。取决于服务器在哪里运行：

| 场景 | 服务器地址 | 说明 |
|------|-----------|------|
| 服务器就在**本机** | `127.0.0.1` | 最常见的测试场景 |
| 服务器在**局域网另一台机器** | 那台机器的内网 IP（如 `192.168.1.100`） | 同一 WiFi/局域网内 |
| 服务器在**公网云服务器** | 公网 IP（如 `39.106.126.188`） | 需开放 9000 端口安全组 |

> 本项目已适配云服务器 `39.106.126.188`，GUI 客户端默认即填此地址。
> 如果你是在本机启动的 `src/server.py`，请把地址改成 `127.0.0.1`。

### 4.3 主界面操作

登录成功后进入主界面：

| 按钮 | 功能 |
|------|------|
| **从系统剪贴板粘贴** | 把系统剪贴板内容读入上方输入框 |
| **加密上传 (PUT)** | 加密输入框内容并上传到服务器 |
| **获取并解密 (GET)** | 从服务器获取密文并解密显示在下方 |
| **复制到系统剪贴板** | 把解密后的内容写入系统剪贴板 |
| **清空输入/输出** | 清空两个文本框 |
| **PING** | 测试连接是否正常 |
| **断开连接** | 发送 EXIT 并返回登录界面 |

### 4.4 典型使用流程

**设备 A 上传：**
1. 启动 GUI，填写服务器地址和登录信息
2. 点击「从系统剪贴板粘贴」或手动输入文本
3. 点击「加密上传」
4. 看到状态栏显示「上传成功」

**设备 B 获取：**
1. 启动 GUI，用**相同的用户名和密码**登录
2. 点击「获取并解密」
3. 明文显示在下方文本框
4. 点击「复制到系统剪贴板」即可使用

> 加密是端到端的：服务器只存密文+盐值，密码错误则解密失败。

## 5. 常见错误

### 「目标计算机积极拒绝，无法连接」

**原因**：指定地址/端口没有服务器在监听。

**排查步骤**：
1. 确认服务器已启动（终端应显示监听信息）
2. 确认地址正确：
   - 本机服务器 → `127.0.0.1`
   - 不要填 `0.0.0.0`（那是服务器监听用的，客户端不能连这个地址）
3. 确认端口一致（默认 `9000`）
4. 确认防火墙没有拦截 9000 端口

### 「登录失败：wrong password」

用户名已注册过，但密码与之前不同。换用正确的密码，或换一个新用户名。

### 登录时提示「该账号已存在」

登录响应包含 `new_account` 标志：新创建的账户状态栏显示「新账户已创建」；登录到已存在的账户会弹出警告。

- 多设备登录同一账户时出现此提示属正常现象
- **若你确信是首次使用该用户名**，说明有他人注册了相同的用户名和密码，对方可解密你上传的全部内容——请立即断开，更换用户名和密码

### 「解密失败」

获取到了密文，但解密失败。通常是密码与上传时的密码不一致。

### 窗口空白或显示异常

Tkinter 依赖系统 GUI 环境。Linux 无桌面环境时需安装 `python3-tk`。

## 6. 云服务器部署（39.106.126.188）

将服务端部署到阿里云 ECS 上，供任意位置的客户端连接。

### 6.1 上传代码

在本机终端执行（Windows PowerShell）：

```powershell
scp src/protocol.py src/server.py root@39.106.126.188:/root/lcecp/
```

### 6.2 放行 9000 端口

**安全组（必须在阿里云控制台操作）：**
1. 登录阿里云控制台 → ECS 实例 → 安全组
2. 添加入方向规则：协议 TCP，端口 `9000`，源 `0.0.0.0/0`

**服务器本机防火墙：**

```bash
# firewalld (CentOS)
firewall-cmd --permanent --add-port=9000/tcp && firewall-cmd --reload

# ufw (Ubuntu)
ufw allow 9000/tcp
```

### 6.3 启动服务端

```bash
ssh root@39.106.126.188
pip install cryptography
cd /root/lcecp

# 前台运行（测试用）
python3 server.py

# 后台常驻（推荐）
nohup python3 server.py > server.log 2>&1 &
```

验证监听是否正常：

```bash
ss -tlnp | grep 9000
```

### 6.4 验证连通性

在本机测试端口是否放通：

```powershell
Test-NetConnection 39.106.126.188 -Port 9000
```

显示 `TcpTestSucceeded : True` 后，启动 `python src/gui_client.py`，默认地址即为该服务器，直接登录即可。

### 6.5 停止服务

```bash
pkill -f server.py
```

## 7. 打包为带图标的启动器（.exe）

无需 Python 环境即可双击运行：

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --icon=assets/app.ico --name=LCECP src/gui_client.py
```

生成 `dist\LCECP.exe`，双击即启动 GUI，图标内嵌于 exe。

相关文件：

| 文件 | 说明 |
|------|------|
| `tools/make_icon.py` | 用 Pillow 生成 `assets/app.ico`（改图标后重跑再重新打包） |
| `assets/app.ico` | 程序图标 |
| `LCECP.spec` | PyInstaller 打包配置，重打包可直接 `pyinstaller LCECP.spec` |

如需桌面快捷方式，右键 `dist\LCECP.exe` → 发送到 → 桌面快捷方式。

## 8. 控制台客户端（备选）

如果不想用 GUI，原始控制台客户端仍可用：

```bash
python src/client.py
```

服务器地址已在 `src/client.py` 第 10-11 行配置为云服务器 `39.106.126.188`，无需修改即可直连。
